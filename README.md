# Lazy Day GitHub Pages

v74에는 시간과 날씨에 따라 바뀌는 하늘과 빗창문의 호버 효과가 포함되어 있습니다.

1. ZIP을 풀고 index.html이 보이는 폴더의 내용물을 게시할 브랜치의 최상위에 올립니다.
2. .nojekyll도 함께 올립니다.
3. 저장소 Settings의 Pages에서 Deploy from a branch를 선택하고, 업로드한 브랜치와 /(root)를 지정합니다.
4. 배포 완료 후 Pages에 표시되는 URL을 엽니다.

건물 모델, 폰트, Three.js, 빗물 텍스처가 포함되어 있습니다. 별도 빌드가 필요 없습니다.
